# PIC QR 체크인 사용설명서

PIC 동아리 챌린지 참여를 QR 코드로 기록하는 관리자용 웹앱입니다.

관리자는 멤버를 등록하고, 멤버별 QR 코드를 발급한 뒤, 챌린지 참여 현장에서 QR을 스캔해서 참여 기록을 남길 수 있습니다.

## 접속 주소

```text
https://pic-beta-blue.vercel.app
```

## 전체 사용 흐름

1. Notion에 챌린지를 만들어 둡니다.
2. 웹앱에서 멤버를 등록합니다.
3. 멤버별 QR 코드를 발급합니다.
4. 행사나 챌린지 현장에서 관리자가 QR을 스캔합니다.
5. 참여명단 페이지에서 오늘 참여한 멤버를 확인합니다.

## 화면별 사용법

### 홈 화면

주소:

```text
/
```

홈 화면에서는 세 가지 기능으로 이동할 수 있습니다.

- `QR 체크인`
- `멤버 등록`
- `참여명단`

### 멤버 등록 / QR 관리

#### 새 멤버 등록

1. `이름`을 입력합니다.
2. `이메일`을 입력합니다.
3. `멤버 등록` 버튼을 누릅니다.

등록이 완료되면 멤버가 Notion 멤버 데이터베이스에 저장됩니다.

#### 중복 등록 방지

이미 같은 이름 또는 같은 이메일로 등록된 멤버가 있으면 새로 등록되지 않습니다.

같은 사람을 실수로 두 번 등록하면 참여 기록이 나뉠 수 있으므로, 기존 멤버인지 먼저 검색하는 것이 좋습니다.

#### 기존 멤버 검색

`기존 멤버 QR 관리` 영역에서 멤버 이름, 이메일, 고유코드로 검색할 수 있습니다.

예시:

```text
최유진
```

검색하면 해당 멤버 카드가 표시됩니다.

#### QR 코드 보기

1. 기존 멤버 목록에서 원하는 멤버를 찾습니다.
2. `QR 보기` 버튼을 누릅니다.
3. 해당 멤버 카드 안에서 바로 QR 코드가 표시됩니다.

QR 코드는 멤버 이름/이메일/고유코드 바로 아래에 나타납니다.

#### QR 코드 발급

QR이 아직 없는 멤버는 `QR 발급` 버튼을 눌러 새 QR 코드를 만들 수 있습니다.

발급된 QR 코드는 멤버의 `Unique Code` 값을 기준으로 생성됩니다.

#### 기존 멤버 전체 QR 발급

`미발급 멤버 전체 발급` 버튼을 누르면 QR 코드가 없는 기존 멤버들에게 한 번에 QR 코드를 발급합니다.

이미 QR 코드가 있는 멤버는 그대로 유지됩니다.

#### QR 코드 재발급

이미 QR 코드가 있는 멤버는 `재발급` 버튼으로 새 QR 코드를 만들 수 있습니다.

주의:

- 재발급하면 기존 QR 코드는 더 이상 사용할 수 없습니다.
- 새로 발급된 QR 코드만 체크인에 사용할 수 있습니다.
- 참여 기록은 유지됩니다.

## QR 체크인

### 체크인 방법

1. `챌린지 이름` 드롭다운에서 오늘 진행할 챌린지를 선택합니다.
2. `카메라 시작` 버튼을 누릅니다.
3. 멤버의 QR 코드를 카메라에 보여줍니다.
4. 스캔이 성공하면 멤버 이름과 체크인 결과가 표시됩니다.

### 중복 체크인

같은 멤버가 같은 날짜에 같은 챌린지로 이미 체크인했다면 중복으로 저장되지 않습니다.

예시:

- 최유진
- 2026-06-28
- Summer Challenge

위 조합으로 이미 체크인했다면 같은 날 같은 챌린지에는 다시 저장되지 않습니다.

다른 날짜나 다른 챌린지는 별도 기록으로 처리됩니다.

## 참여명단 확인

오늘 참여한 멤버 목록을 확인하는 화면입니다.

### 확인 방법

1. `챌린지 이름` 드롭다운에서 챌린지를 선택합니다.
2. `참여명단 불러오기` 버튼을 누릅니다.
3. 오늘 해당 챌린지에 참여한 멤버 목록을 확인합니다.

표시되는 정보:

- 멤버 이름
- 이메일
- 체크인 시간

## Notion에서 관리하는 데이터

이 앱은 Notion 데이터베이스 2개를 사용합니다.

### 멤버 데이터베이스

멤버 정보와 QR 코드를 저장합니다.

필요한 속성:

| 속성 이름 | 타입 | 설명 |
| --- | --- | --- |
| `Name` | Title | 멤버 이름 |
| `Email` | Email | 멤버 이메일 |
| `Unique Code` | Rich text | QR 코드 생성에 사용하는 고유 코드 |

### 챌린지 데이터베이스

챌린지별 참여 기록을 저장합니다.

필요한 속성:

| 속성 이름 | 타입 | 설명 |
| --- | --- | --- |
| `Challenge Name` | Title | 챌린지 이름 |
| `Date` | Date | 참여 날짜 |
| `Participants` | Relation | 참여한 멤버 목록 |

`Participants`는 멤버 데이터베이스와 연결되어 있어야 합니다.

## 챌린지 추가 방법

Notion 챌린지 데이터베이스에서 새 페이지를 추가합니다.

필수로 입력할 값:

- `Challenge Name`

앱의 `/scan`, `/checkins` 화면에서는 Notion에 있는 챌린지 이름을 드롭다운으로 불러옵니다.

## QR 코드와 참여 횟수

QR 코드는 멤버의 `Unique Code`로 만들어집니다.

참여 기록은 QR 이미지 자체가 아니라 Notion의 멤버 페이지와 연결됩니다.

그래서:

- QR을 다시 보기만 하면 기존 QR을 그대로 사용합니다.
- QR을 재발급하면 새 QR 코드가 만들어집니다.
- QR을 재발급해도 기존 참여 기록은 사라지지 않습니다.
- 같은 사람을 새 멤버로 다시 등록하면 참여 기록이 나뉠 수 있습니다.

## 휴대폰에서 앱처럼 사용하기

iPhone Safari 기준:

1. 배포 주소에 접속합니다.
2. 하단 공유 버튼을 누릅니다.
3. `홈 화면에 추가`를 선택합니다.
4. 홈 화면에 생긴 아이콘으로 접속합니다.

카메라 스캔은 HTTPS 주소에서 사용하는 것이 좋습니다.

## 관리자 주의사항

- 같은 멤버를 중복 등록하지 않도록 먼저 검색합니다.
- QR 재발급 후에는 예전 QR이 작동하지 않습니다.
- Notion 데이터베이스의 속성 이름을 임의로 바꾸면 앱이 작동하지 않을 수 있습니다.
- `.env.local` 파일은 GitHub에 올리면 안 됩니다.
- Notion 토큰은 외부에 공유하지 않습니다.

## 개발자용 실행 방법

패키지 설치:

```bash
npm install
```

개발 서버 실행:

```bash
npm run dev
```

HTTPS 개발 서버 실행:

```bash
npm run dev:https
```

빌드 확인:

```bash
npm run build
```

Lint 확인:

```bash
npm run lint
```

## 환경변수

`.env.local`에 필요한 값:

```env
NOTION_TOKEN=
NOTION_MEMBERS_DATABASE_ID=
NOTION_MEMBERS_DATA_SOURCE_ID=
NOTION_CHECKINS_DATABASE_ID=
NOTION_CHECKINS_DATA_SOURCE_ID=
```

Vercel에 배포할 때도 같은 값을 Vercel 환경변수에 등록해야 합니다.
